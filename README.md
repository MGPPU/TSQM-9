# TSQM-9 Questionnaire Application

Статическое веб-приложение на базе архитектуры PWA (Progressive Web App), предназначенное для автоматизированного расчета и анализа удовлетворенности пациентов проводимой медикаментозной терапией на основе валидированного медицинского опросника TSQM-9 (Treatment Satisfaction Questionnaire for Medication).

Приложение оптимизировано для мобильных устройств, поддерживает автономный режим работы и интегрировано с облачным сервисом хранения данных Google Sheets.

## Что реализовано

- 9 вопросов в формате многоэкранного wizard-интерфейса.
- Расчет 3 ключевых шкал удовлетворенности прямо в браузере.
- Компактный экран результата с радарной диаграммой на элементе Canvas.
- Локальный черновик прохождения в `localStorage` для защиты от случайного закрытия вкладки.
- Необязательное поле ввода ФИО / ID пациента на стартовом экране.
- Скачивание полной копии результатов тестирования в формате JSON.
- Автоматическая фоновая отправка результатов в Google Таблицы сразу после фиксации финального ответа.
- Защита от дублирования записей при повторных кликах (Double-Click Prevention).

## Структура проекта

- `index.html` — главная разметка приложения и экраны тестирования.
- `manifest.json` — манифест PWA (настройки интеграции, цвета и пути к иконкам приложения).
- `sw.js` — Service Worker (логика кэширования ресурсов для обеспечения офлайн-доступа).
- `css/style.css` — оформление интерфейса (Glassmorphism), анимации и медиа-запросы.
- `js/app.js` — логика интерфейса, управление конфигурацией CONFIG и транспортный слой API.
- `js/questions.js` — конфигурация базы вопросов и вариантов ответов.
- `js/calculator.js` — математический модуль расчета шкал TSQM-9.
- `google-apps-script/Code.js` — серверный скрипт для интеграции с Google Sheets.

## Локальный запуск

Для корректной работы всех PWA-компонентов (включая регистрацию Service Worker), а также для тестирования отправки сетевых запросов, рекомендуется поднимать локальный статический сервер, а не открывать HTML-файл напрямую.

Пример запуска через Python:
```powershell
python -m http.server 8080
```

После этого приложение будет доступно по адресу:

```
http://localhost:8080
```

## Математическая модель расчета

Расчет удовлетворенности производится по 100-балльной шкале независимо для трех доменов:
1. Эффективность (Effectiveness): Вопросы 1–3.
2. Удобство применения (Convenience): Вопросы 4–6.
3. Общая удовлетворенность (Global Satisfaction): Вопросы 7–9.

Алгоритм калькулятора учитывает специфика медицинских развилок (включая пропущенные секции при отсутствии побочных эффектов) и выполняет корректное нормирование баллов. При наличии пропущенных вопросов в таблицу передается маркер прочерка "—", что исключает смещение ячеек.

## Настройка интеграции

Прямо по URL таблицы браузер записывать строки не может, поэтому используется Google Apps Script в качестве веб-приложения.

1. Откройте файл google-apps-script/Code.js.
2. Перенесите его содержимое в редактор Apps Script вашей Google Таблицы согласно инструкции в папке скрипта.
3. Опубликуйте скрипт как Веб-приложение (Web app).
4. Скопируйте полученный URL и вставьте его в файл js/app.js в блок CONFIG:

const CONFIG = {
    GOOGLE_SCRIPT_URL: "[https://script.google.com/macros/s/.../exec](https://script.google.com/macros/s/.../exec)",
    GOOGLE_SHEET_URL: "[https://docs.google.com/spreadsheets/d/.../edit](https://docs.google.com/spreadsheets/d/.../edit)"
};
