# Автоматизированный аналитический комплекс TSQM-9

Данный программный комплекс представляет собой автономное веб-приложение для цифрового анкетирования и экспресс-оценки удовлетворенности пациентов медикаментозной терапией по международной методологии TSQM-9 (Treatment Satisfaction Questionnaire for Medication).

Система спроектирована как полноценное мобильное решение, функционирующее без обязательного подключения к сети и обеспечивающее централизованный сбор метрик в облачную базу данных.

## Архитектура PWA (Progressive Web App) и автономность

Ключевой технической особенностью проекта является его полная независимость от стабильности интернет-соединения благодаря архитектурным возможностям PWA:

- Автономная работа (Offline Mode): Скрипт sw.js перехватывает сетевые запросы и кэширует статические ресурсы (HTML, CSS, JS). Тестирование можно запустить и полностью пройти в условиях полного отсутствия связи (например, в медицинских учреждениях с плохим покрытием сети).
- Нативная инсталляция: Наличие файла manifest.json позволяет пациенту или врачу установить приложение на экран смартфона или рабочий стол ПК в один клик. Приложение работает в изолированном окне без интерфейса браузера, адаптируясь под экраны любых мобильных устройств.
- Сохранение сессии (Draft Recovery): Внутреннее состояние визарда непрерывно синхронизируется с localStorage. При случайной перезагрузке страницы или закрытии приложения пациент возвращается к тому вопросу, на котором остановился.

## Ключевой функционал системы

- Пошаговый интерактивный опросник из 9 валидированных пунктов.
- Динамический расчет профиля удовлетворенности по 3 независимым медицинским шкалам.
- Встроенная генерация радарной диаграммы (Canvas) для мгновенной интерпретации результатов.
- Персонализация данных (ввод ФИО или ID на старте) с возможностью полностью анонимного прохождения.
- Локальный экспорт результатов в файл формата JSON для личного архива пациента.
- Бесшовная фоновая отправка данных в Google Таблицы с интегрированной защитой от дублирования строк при нестабильном сигнале.

## Состав программного комплекса

- index.html — разметка интерфейса и экранов анкетирования.
- manifest.json — конфигурационный файл спецификации PWA, иконок и темы оформления.
- sw.js — сервис-воркер, управляющий стратегией кэширования и офлайн-доступом.
- css/style.css — визуальное оформление в стиле матового стекла (Glassmorphism) и адаптивная верстка.
- js/app.js — координатор интерфейса, валидатор шагов и транспортный клиент API.
- js/questions.js — структурированный массив данных с текстами вопросов и весами ответов.
- js/calculator.js — математический движок, нормирующий баллы шкал от 0 до 100.
- google-apps-script/Code.js — программное обеспечение бэкенда для обработки входящих данных на стороне Google Таблиц.

## Порядок локального запуска

Для корректного развертывания сервис-воркера (sw.js) и обработки сетевых транзакций запуск приложения должен осуществляться через веб-сервер, а не локальный файловый протокол (file://).

Команда для запуска веб-сервера через среду Python:
```
python -m http.server 8080
```

После активации сервера приложение доступно по адресу:
```
http://localhost:8080
```

## Специфика калькулятора шкал

Интегрированный калькулятор вычисляет индекс удовлетворенности по трем доменам (Эффективность, Удобство, Общая оценка). Алгоритм учитывает медицинские развилки: если определенные вопросы пропускаются (например, из-за отсутствия побочных эффектов), система корректно пересчитывает пропорции, а в облачную таблицу вместо пропущенных ответов передается защитный символ "—", предотвращающий сдвиг аналитических колонок.

## Привязка облачной базы данных

Связь между фронтендом и таблицей Google Sheets настраивается через удаленный вызов веб-приложения Apps Script.

1. Скопируйте серверный код из папки google-apps-script/Code.js в редактор скриптов вашей таблицы.
2. Пройдите процедуру деплоя в режиме Web App с доступом для всех (Anyone).
3. Перенесите сгенерированный адрес шлюза в конфигурационную константу CONFIG внутри файла js/app.js:
```
const CONFIG = {
    GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/.../exec",
    GOOGLE_SHEET_URL: "https://docs.google.com/spreadsheets/d/.../edit"
};
```
